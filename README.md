# Numerical Methods

Visual lectures and self-paced practice pages for a first course in Numerical Methods.

Live site: https://biswarupbiswas.github.io/numerical-methods/

## Build and deploy

```bash
pip install -r requirements.txt
./sync.sh            # pull latest practice pages, thumbnails and MATLAB files from ../numerical_methods
mkdocs serve         # preview at http://127.0.0.1:8000
mkdocs gh-deploy     # build and publish to the gh-pages branch
```
